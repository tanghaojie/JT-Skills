# 原始提示词收集区

这里存放尚未整理成 Skill 的提示词、有效示例和使用反馈。先保存原始内容，再归类，不要求一次整理完成。

## 保存方式

- 每个任务或一组紧密相关的提示词保存为一个 Markdown 文件。
- 建议命名为 `YYYY-MM-DD-任务简称.md`；同名时增加简短区分词。
- 可以直接粘贴原文，也可以复制 [prompt.md.template](../templates/prompt.md.template)，记录用途、输入和满意结果。
- 保存前去掉密码、令牌、客户隐私等不适合入库的信息。
- 整理完成后保留原文，补上目标 Skill 的相对链接，方便追溯与继续改进。

收集文件不是可调用 Skill，文件名不要使用 `SKILL.md`。
