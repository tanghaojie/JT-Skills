# 软件开发

收录以软件代码、系统设计或运行结果为主要交付的 Skill。只服务于某个写作、建模或文档任务的辅助脚本，随该领域的 Skill 管理。

## 整理方向

以下是分类建议，不代表已实现的 Skill；有实际提示词时再创建相应目录。

| 环节 | 可整理的任务 |
| --- | --- |
| 需求与设计 | 需求拆解、验收条件、架构方案、接口设计 |
| 功能实现 | 前端页面、后端接口、数据处理、项目脚手架 |
| 问题定位 | 错误复现、日志分析、故障修复 |
| 质量改进 | 代码审查、测试设计、重构、性能优化 |
| 交付维护 | 发布检查、部署验证、开发文档、依赖维护 |
