# 导演与叙事

从 Lemo-Opuscar 的导演方法提炼。画面好看只是起点，声音、节奏、镜头和表演一起服务本片的表达目的。下面的数量是普通 30–60 秒影片的工作起点，短测试片、静音片和用户特定形式按实际需要缩减。

## 拍什么

一个主要对象、一项目的、一次变化。开头约 3 秒内让观众知道值得看什么；结尾回应开场、揭示尺度或呈现变化。纯信息片也需要“问题 → 证据 → 理解变化”，不强塞人物冲突。

选 1–2 个贴合主题的参照，只学习构图、节奏、镜头或声音组织；在方案中记录学习点，不把参照的角色、设计、配乐、标志或具体镜头作为本片资产。

所选 `STYLE.md` 管风格；故事、结构、角色、场景、信息顺序和时间表从用户主题出发。先独立写方案，避免把 demo 换个标题就交付。技术借用后，对比结构、开场、标志镜头、摄影路径、音乐结构、结尾；若大半相同，回到方案重构，而非机械替换四处元素。

## TREATMENT.md 应能指导制作

按项目规模组织以下信息，不必生搬章节：

| 内容 | 应回答的问题 |
| --- | --- |
| 需求与假设 | 给谁看、在哪里看、交付什么；主题、时长、语言、画幅、fps、声音和审片要求从哪里来 |
| 结构选择 | 普通影片简述 2–3 种结构候选，选择及原因；短风格测试可以只写一种 |
| 一句话与弧线 | 开场状态、转折、落点，以及最值得记住的画面 |
| 参照 | 学什么、不取什么、与本片主题的关系 |
| 镜头表 | 每镜时间范围、景别、角度、运动、动作、叙事理由 |
| 节拍与声音 | 分段 tempo、节拍、切点、动作音、环境底、配器、留白；无需音乐的片型说明替代节奏 |
| 文案与字幕 | 旁白、屏幕文字、可读时长、字体、布局与安全区 |
| 资料与限制 | 素材出处、事实待核项、许可、设备或工具限制 |

把节拍和关键动作转入机器可读的唯一时间轴，后续更新回写这份方案；文档不能成为与实现脱节的旧版本。

## 风格帧与分镜

- 有角色：角色转面、主要表情与关键姿势，加 2 张真实风格帧。
- 无角色：约 3 张风格帧，其中一张展示标志镜头。
- 画面要来自实际渲染代码，检查最终尺寸下的文字、遮挡、轮廓、色彩和材质。
- 用户要求先审分镜：约 6–9 个关键镜头组成联系表，附镜号、景别、时长、台词与不确定点，再交给用户审阅。用户已有明确授权自行决定时沿用授权。

## 声音、节奏、镜头、表演

声音按环境、拟音、音乐分层；有意义的动作对应材质合适的声音，旁白时降低背景音。转折前适当留白，J-cut 或 L-cut 可以连起场景；次数服从叙事。配器采用风格的声音调色板，不能所有片子都套钢琴弦乐。

快慢需要变化。字幕与数字先保证能读，再压缩时长。镜头运动要有理由：接近人物、揭示关系、展示尺度或跟随动作。二维画面同样可以有推进、拉远、视差与景深。转场使用当前媒介的动作，例如折纸、水墨扩散或网格重组；风格要求硬切时不强加溶解。

角色动作包含预备、动作、缓冲。姿势连续插值，重要动作逐帧看；拿取物体时跟踪双手和遮挡，滚动物体按路程与半径计算角度。世界到屏幕坐标统一变换，光圈、聚光、跟随镜头不能各自猜坐标。
