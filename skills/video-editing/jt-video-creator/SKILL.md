# 中文视频创作

把主题、素材与风格变成有叙事、声音和镜头设计的短片。默认使用 Canvas、WebGL 或 three.js 生成画面，以统一时间轴驱动配音、音乐、拟音和字幕，再逐帧渲染为视频。实证与纪实风格可以使用真实影像、扫描件和数据；不要用生成画面冒充真实记录。

本 Skill 中文改编自 LemoLab 的 Lemo-Opuscar，版本与改编范围见 [来源说明](references/sources.md)，许可见 [LICENSE](LICENSE)。默认不依赖图像或视频生成服务；用户明确指定其他工具时保留其选择，重新核对执行链。

## 入口与输入

- **制作影片**：需要主题或资料、目标观众、用途；时长、画幅、风格、声音、字幕、品牌素材和输出位置按用户已给的信息执行。
- **选择风格**：先找用户指定位置、当前项目 `my-styles/` 或 `JT_VIDEO_STYLES_HOME` 的个人风格索引，再查 [59 种风格目录](references/styles.md)。无明确偏好时推荐 2–3 种并说明理由；用户说“你定”就选，不强制展示整份目录或重复确认。
- **改造、创建或复用个人风格**：按 [个人风格](references/custom-styles.md) 执行。只改本片故事、文案或时长，不必建立新风格。
- 只有 Skill 名称而无任务时，用中文询问是制作影片、浏览风格还是创建个人风格。当前消息已有任务时直接进入，不再问语言。

先检查当前项目已有需求、素材和工具。合并询问真正缺失且影响结果的信息；已明确的信息不重问。缺少事实、素材或必要工具时指出受阻阶段，同时继续不依赖它的方案工作。不要凭空编造用户产品参数、经历或已获得的授权。

未指定时采用可调整的起点：30–60 秒、1920×1080、24 fps、简体中文配音和字幕；竖屏用途优先按目标平台重排布局。优先级为用户要求 → 当前项目约束 → 风格专属参数 → 默认值；在 `TREATMENT.md` 记录最终参数。用户要求静音、无字幕、离线或指定配音时据此裁减流程。

## 执行

1. **确认可执行路径**：阅读 [工具链](references/toolchain.md)，检查实际版本、浏览器、字体、可用声音方案与磁盘空间。固定版本工具库按需下载，工程依赖放在项目或独立工具库内。不得运行上游的自动更新脚本代替本地流程。
2. **读取所选风格**：通过工具链取得完整 `styles/<slug>/STYLE.md`，用中文提炼不可变的材质、色彩、字体、运动、镜头、声音和标志动作。不能只凭目录名或演示截图猜测。缺少完整规则且当前不能获取时，可以交付标注“风格待核验”的方案，但不得宣称风格已复现。原文中的产品名、示例素材、英语配音和固定示例布局不自动成为本片要求。
3. **先创作再借技术**：阅读 [导演与叙事](references/directing.md)，先写本片 `TREATMENT.md`，再读上游 `DEMO.md` 与 demo 代码。纪实片可先读风格明确指定的素材检索工具；个人风格可先读技术实现以制作风格帧，这两种例外不授权照搬示例故事。
4. **证明画面**：用最终绘制代码产出风格帧，检查中文、主体尺度与关键动作。用户要求先审分镜时，先完成可审阅的分镜与说明，等待其反馈；未要求时自行检查并继续，不设置固定审批关卡。
5. **制作**：按 [制作规范](references/production.md) 落实唯一时间轴、录音或 TTS、配音核对、音乐与拟音、动画、字幕、渲染、混音与封装。工程放在用户指定目录，或当前目录下独立的小写连字符文件夹；不要在 Skill、工具库或上游 `styles/` 中制作影片。
6. **验收与交付**：按 [验收清单](references/quality.md) 检查成片与重建命令，修正有证据的问题后复查。无进展的同类失败最多重试两次，再报告原因、已完成内容与可选路径；不要静默换声音、换风格、降分辨率或无限重跑昂贵渲染。

## 交付

交付 `影片名.mp4`、`poster.jpg`、适用时的 `.srt`、`TREATMENT.md`、`CREDITS.md`、完整工程与可从任意目录调用的一条重建命令（`build.py`、`build.ps1` 或 `build.sh`）。涉及事实的影片另交 `FACTS.md` 和素材来源清单。个人风格交付按其专用说明。

收尾用中文给出实际路径、规格、已完成检查和未验证项。自动化检查不能代替观看和听音；没有播放能力时直说，不宣称已完整视听验收。仅制作方案时不伪造视频路径；仅整理此 Skill 不代表已安装到宿主或已发布影片。
