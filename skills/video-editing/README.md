# 视频剪辑

收录以剪辑工程、视频成片或后期素材为主要结果的 Skill。纯口播稿写作放入[写作](../writing/README.md)，三维动画资产制作放入[三维建模](../3d-modeling/README.md)。

## 整理方向

以下是分类建议，不代表已实现的 Skill；有实际提示词时再创建相应目录。

| 环节 | 可整理的任务 |
| --- | --- |
| 素材准备 | 素材命名、镜头筛选、转写与时间码整理 |
| 剪辑组织 | 粗剪、口播精剪、节奏调整、补充镜头安排 |
| 字幕处理 | 字幕校对、断句、时间轴对齐、字幕样式 |
| 音画后期 | 降噪、音量调整、配乐、转场、调色与动效 |
| 成片交付 | 横竖版适配、导出参数、画面与声音验收 |
