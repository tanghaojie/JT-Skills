# 三维建模

收录以三维资产、场景或模型动画为主要结果的 Skill。围绕模型交付的脚本可留在该 Skill 内；通用应用开发归入[软件开发](../software-development/README.md)。

## 整理方向

以下是分类建议，不代表已实现的 Skill；有实际提示词时再创建相应目录。

| 环节 | 可整理的任务 |
| --- | --- |
| 参考研究 | 参考图收集、来源记录、尺寸与结构分析 |
| 模型构建 | 建筑、产品、场景、程序化建模 |
| 视觉表现 | 材质、贴图、灯光、构图与渲染 |
| 动画制作 | 装配、拆解、镜头运动、动作设计 |
| 资产交付 | 拓扑检查、体积优化、格式导出、参考对照验收 |
