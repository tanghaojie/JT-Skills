# 跨领域通用

收录在多个领域中输入、步骤和交付标准基本相同的独立任务。只有名称相似、实际做法不同的任务，仍保留在各自领域。

## 整理方向

以下是分类建议，不代表已实现的 Skill；有实际提示词时再创建相应目录。

| 方向 | 可整理的任务 |
| --- | --- |
| 需求整理 | 把零散要求整理成输入、约束与验收标准 |
| 资料核验 | 来源登记、事实与推断区分、证据缺口整理 |
| 交付检查 | 按明确的验收要求检查产物与证据 |

优先让各领域 Skill 自包含。仅在实际复用有收益时抽出通用 Skill，避免为了复用而引入不必要的依赖。
