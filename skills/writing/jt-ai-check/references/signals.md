| 编号 | 观察什么 | 成立所需的上下文与防误判 |
| --- | --- | --- |
| D01 | 连续预设反驳并逐一封堵 | 说明哪些辩解没有回应实际论点；必要风险说明及正式论证不因完整而有罪 |
| D02 | 把背景知识倾倒进正文 | 指出与当前问题无关的材料；必要术语、数据与技术解释保留 |
| D03 | 成组修辞力度与节奏过于一致 | 检查是否用对称代替内容；并列事实与清单不自动算排比 |
| D04 | 多段复用同一种让步展开 | 至少给两处证据，并说明重复骨架如何限制论证 |
| D05 | 反复隆重命名新概念 | 检查命名是否增加区分度；正式定义、术语介绍本身合理 |
| D06 | 情绪推进过于程式化 | 须有与材料脱节的情绪证据；情绪平稳、叙事完整不单独扣分 |
| D07 | 虚设一个易反驳的读者立场 | 有矮化或无依据归因才计；实际引述的反对意见不算 |
| D08 | 连续通过否定与翻转制造洞见 | 结合密度和功能，真实概念区别不因句型相似扣分 |
| D09 | 所有结论均作确定陈述 | 只有材料不支持确定性时才计；明确事实不要求装出犹豫 |
| D10 | 情绪细节使用异常精确的量化 | 先列待核实；真实计时、实验记录不因精确受罚 |
| D11 | 个人脆弱叙事恰好服务于每个论点 | 只能指出叙事模板，不能凭结构推定人生经历是假的 |
| D12 | 结尾方案把前文复杂性一笔抹平 | 说明前文条件怎样被后文方案丢掉；合理操作清单可以成立 |
| D13 | 各段都以可摘抄式警句收尾 | 长文检查是否重复或空泛；短视频不以金句收尾本身扣分 |
| D14 | 句段长度与力度缺少内容驱动的变化 | 多段样本才评，短帖不适用；不建议靠随意断句改善分数 |
| D15 | 身体感受被当作结论的唯一根据 | 需要论证的主张才计；记录感受本身无需变成学术论证 |
| D16 | 开头套抓眼球、焦虑、结果保证 | 检查是否替代了具体主题或作无支持承诺；不因开头有吸引力扣分 |
| D17 | 连接和提示语反复出现在固定位置 | 判断是否承担逻辑功能；必要时序、因果不算套话 |
| D18 | 同一对象被不断换名称 | 只有制造冗余或指代混乱才计；必要概念区别不合并 |
| D19 | 句子受翻译式长修饰和名词化支配 | 看主语、动作、可读性；“作为”“基于”等词单独出现不成立 |
| D20 | 用高度便利的故事充当证据 | 区分明确虚构案例、匿名真实案例和来源不明陈述；不要求公开私人身份 |
| D21 | 结束后再追加泛化祝愿 | 只在无信息、与场景无关时计；致辞和私人通信可以需要祝愿 |
| D22 | 把具体问题突然拔高为宏大命题 | 说明推论缺失的位置；主题本身是抽象讨论时不机械扣分 |

## 体裁调整

- **公众号或评论长文**：可检视全部方向，但仍逐项判断语境，不必为了覆盖 22 项而输出 22 条问题。
- **短视频口播**：不以段尾警句、短句、重复提示本身扣 AI 味；检查空话和承诺是否挤占有效信息。JT 的个人规则另行评判。
- **短帖、标题、单段节选**：不评价全文闭环或整体情绪曲线；样本不足的结构和节奏维度标信息不足，不伪造完整评分。
- **技术、学术、正式说明**：术语、穷尽条件、定义、风险边界和一致结构可能是任务要求。只评价不必要的重复或真实表达问题，不把专业性当机器味。
- **演讲、营销、文学、私人通信**：结合使用目的判断铺垫、修辞、祝愿；用户指定的任务目标优先。JT 偏好冲突单列。
- **引文、代码、公式与模板**：标清归属，通常不纳入作者风格评分。只有作者自己的引入、解释或重复使用方式构成问题时评价该部分。

## 飞书资料的吸收边界

从“人味噪点、结构、身份、记忆”四个方向提炼三个检查问题：表达是否被模板牵着走，作者视角是否适合读者与任务，个性化陈述是否有材料依据。

不把噪点多少、情绪强弱、MBTI 类型或记忆细节数量作为加分条件；不要求每篇文章都有自我修正和人生故事。具体性来自现有证据，口语化也不能牺牲准确性。不把该文中的脑科学措辞写成已经验证的评分依据。
