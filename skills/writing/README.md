# 写作

收录以文字内容创作为主要结果的 Skill。文档排版、文件转换归入[文档处理](../document-processing/README.md)；视频剪辑相关字幕和包装归入[视频剪辑](../video-editing/README.md)。

## 整理方向

以下是分类建议，不代表已实现的 Skill；有实际提示词时再创建相应目录。

| 环节 | 可整理的任务 |
| --- | --- |
| 选题策划 | 选题筛选、读者定位、切入角度、内容提纲 |
| 资料准备 | 来源整理、素材提炼、采访资料处理 |
| 正文创作 | 长文、短文、公众号文章、视频口播稿 |
| 编辑改写 | 结构调整、风格改写、压缩扩写、去除空话 |
| 发布准备 | 标题、摘要、导语、事实核验与内容审校 |
