# 交易阶段与盘中数据

## 阶段识别

以下为 2026-10-22 资料核对所用的沪深竞价规则。真正涉及具体品种、交易日及委托处理时重新核对当前规则，关注节假日、停牌和盘后机制，不能推广到其他市场。

| 当地时间／阶段 | 分析约束 |
| --- | --- |
| 9:15—9:20 开盘集合竞价前段 | 接受申报，可撤销未成交申报；撤单须交易主机确认。参考价和匹配量仍会变化，撤单行为本身不能证明操纵意图 |
| 9:20—9:25 开盘集合竞价后段 | 不接受撤单申报，但仍可新增有效申报；不能把不可撤单等同于已经成交或价格不会再变 |
| 9:25 撮合结果及至 9:30 的衔接 | 分开记录竞价最终结果与随后委托处理；券商接受委托不等于交易所已经接收，不自行假定该阶段可撤或已成交 |
| 9:30—11:30、13:00—14:57 连续竞价 | 累计成交比较使用相同的已交易时长；午间休市不计入交易分钟 |
| 14:57—15:00 收盘集合竞价 | 撤单受限，尚未形成的收盘价不能提前当作事实 |
| 其他盘后阶段 | 按品种实际支持的机制处理，不把盘后固定价格成交与连续竞价指标混算 |

普通 A 股当日新买入部分通常不能当日卖出；原有可卖持仓需单独检查。给出交易条件时考虑停牌、涨跌停、可卖数量及对手盘，触发止损不保证成交。未核实品种规则时只描述观察，不宣称某委托必可执行。

## 指标与同步

- 指数、板块、个股比较使用同一截止时点和可比区间。相对强弱可用两者涨跌幅之差，单位为百分点；同时写明基准，不把它称为 RSI。
- 累计成交与前日同一时段比较，不直接与昨天全天比较。若仅有昨天全天量，只能展示背景，不能下“同比放量”的结论。成交额增加也不能单独证明新增资金入市。
- 常见分时量比：`截至当前累计成交量 ÷（过去 5 个交易日平均每分钟成交量 × 当日已交易分钟数）`。统一股／手单位；缺分母、无足够历史或停牌期间不强算。竞价和盘后是否计入按供应商定义；竞价匹配量不能代替连续竞价已成交量套公式。
- 指数黄白线必须读取平台图例与指数编制口径；不能默认每条黄线都等于全市场等权指数。两线同涨不代表所有或多数个股都涨，用市场宽度验证。
- 个股均价线需确认算法；若为成交量加权均价，单位对齐后以累计成交额／累计成交股数计算。当前价格在均价线上方不证明过去一直在上方，单张快照不能证明每次回调都获支撑。
- 市场涨跌家数、涨跌停和板块内部宽度写明股票池、分类与时间。概念板块可能重复包含个股；没有分类覆盖信息就不能把板块成交额加总当作市场总额。
- 资金流的主动买卖方向、大单分类和合并算法由供应商决定。大单／小单不等于机构／散户身份。来源冲突先检查时间与口径，不挑选符合观点的数据。
- 北向通道数据、机构定期持仓和所谓游资席位并非可同时实时观测的互斥类别。季度持仓不可与当日估算组成“同步加仓”；多日累计供应商指标也不能证明真实意图。

## 证据解释

新闻与价格同向只提供可能解释，先核对来源及披露时间。板块主线候选结合成交、广度、领涨结构、延续性及催化；只有当前截面时不宣称已连续领涨。原文数量、时间、涨幅阈值不自动成为固定参数。

量价形态允许多种解释：慢涨缩量不能证明高度控盘，价格创新低而量未创新低不代表卖压衰减，V 形也可能随后失效。需要给出未来能验证或推翻判断的条件，不能从图形直接推断真实持有人动机。
