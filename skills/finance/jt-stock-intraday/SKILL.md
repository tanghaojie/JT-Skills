# 股票盘中观察

交付截至指定时点的大盘、板块、个股观察记录。围绕资金、情绪和强弱判断当前证据，说明相对盘前预期或上一快照发生了什么变化。一次调用提供一次分析；只有当前任务另行建立并确认运行的监控才可称为持续跟踪。

## 时点与数据准备

1. 确认市场与品种、交易日、当前阶段、行情截止时点、用户关注的个股及已有计划。交易时段按交易所当地时间标注，区别用户本地时间；历史截图按截图时间解释，不称实时行情。
2. 检查已有只读行情、公告工具和用户截图／导出表。优先使用可验证时间戳及指标口径的来源，注明延迟。没有实时数据就分析已有快照；没有历史快照就不能声称“正在增强”。关键层级缺数据时暂停该层结论，继续有证据的层级。
3. 仅使用截止时点已经公开的信息。涨幅、累计成交、板块宽度和个股指标尽量对齐同一时点；不同时间分别标注，不拼成同步共振。截图模糊或只有曲线时不猜精确数字。
4. 明确大盘基准、板块分类、自选范围与量价单位。未给个股时先做大盘板块，标注个股待补；不自称知道用户持仓、成本、模式或风险承受能力。

分析竞价、比较成交、计算指标或对照交易触发条件时，读取 [references/session-and-data.md](references/session-and-data.md) 对应部分。该文件随 Skill 一起使用，无需其他 Skill 或 inbox。

## 三个层级，三条线索

每次分析按大盘 → 板块 → 个股展开；只提供单层资料时，其他层级明确缺口，不编造背景。盘前尚无当日成交时，以下指标使用前一交易日作背景并明确日期，不能当成当日表现。

| 层级 | 资金与成交 | 赚钱效应与情绪 | 相对强弱 |
| --- | --- | --- | --- |
| 大盘 | 指数和全市场量价，累计成交与前一交易日同一交易时段比较；检查覆盖范围 | 涨跌家数、涨跌停与涨跌幅分布；有数据时看强势股延续与炸板，辨别指数和多数股票表现是否背离 | 主要指数、大小盘或权重与题材风格变化；黄白线仅在图例和编制口径明确后解释 |
| 板块 | 涨跌幅榜前列、成交额集中度与变化，资金流须带供应商口径 | 板块上涨广度、涨停集中与扩散、领涨股和其他成份股的跟随或分化 | 相对大盘表现、与前次快照及此前交易日比较，区分主线候选、轮动、分歧和转弱；催化须有公开来源 |
| 个股 | 高低开与预期差，分时成交、均价线、量比或换手；价格所在区间与放缩量结合 | 拉升后能否保持、回调是否有成交承接、冲高回落及板块配合；不用走势推断账户心理 | 同区间对照大盘和所属板块；开盘价、前收盘价、均价线、可见支撑压力的位置与突破／跌破行为 |

输出三层之间的关系：个股是否强于板块，板块是否强于大盘，赚钱效应是否配合价格强势。证据分歧可以得到“暂不确认”，不强行合成为买卖信号。

## 按所处阶段补充观察

只展开当前阶段需要的内容，不每次重复全天教程。

- **盘前**：核对美股代表指数、A50 对应合约和美元／人民币报价的时间与方向，作为风险偏好背景；检查持仓自选公告、政策与数据日程；整理用户已有预期、观察触发、止盈止损及失效条件。缺少用户参数时标记待定，不擅设仓位和止损百分比。
- **开盘集合竞价**：对比大盘参考开盘水平、板块聚集和个股竞价相对前收盘及事前预期的差异。区分参考价、匹配量、未匹配量与最终成交；未到撮合结果不能说已经按参考价成交，不凭撤单识别骗单者。
- **开盘初段**：用与昨天同一时段可比的成交判断活动变化；观察领涨板块是否扩散、个股开盘价／均价线附近的承接及回落。9:30—10:00 是观察窗口示例，不是 10 点后方向已经确定的规则。
- **后续盘中及尾盘**：与上一快照对照，记录市场广度、板块排名与个股强弱是否改变。保持午间休市、收盘竞价与盘后交易的阶段区别，不把尚未发生的收盘结果写进当前结论。

## 从观察到条件

为重点板块和个股给出“当前事实 → 可能解释 → 反证／缺口 → 下一观察条件”。条件应可在之后验证，例如价格是否保持在已识别区间上方、板块广度是否继续改善；明确判断窗口，不使用无定义的“站稳”代替条件。

“3 只涨停”“连续 3 天”“高低开 2%—4%”和量比固定阈值只是原文经验例子，不能成为无条件主线或买点规则。台阶上涨、V 形、急拉回落和慢涨缩量可描述，不断言洗盘、出货、控盘或确定见底。

有明确事前计划时逐项对照触发、失效及数据条件。没有计划时交付观察条件；若用户要求形成具体交易方案，再取得影响仓位和可执行性的必要输入。普通 A 股当日新买与原有可卖持仓分开，不能用理论止损价替代成交可行性。本 Skill 调用本身不包含下单或账户修改。

## 交付

默认简体中文，先给当前结论，再给证据：

1. **时点卡**：交易日、交易所当地时间、阶段、数据来源及延迟、覆盖范围。只有旧快照时在结论附近明确指出。
2. **大盘 → 板块 → 个股**：关键事实、资金／赚钱效应／强弱判断及反证；有前次快照时写出变化，无前次数据则只描述现状。
3. **观察清单**：对象、条件、失效信号、所需新数据；明确哪些来自用户既定计划，哪些只是本次观察假设。
4. **缺口**：只列影响当前判断的缺失信息，不把可选数据缺失变成整个任务停摆。

给数值注明单位、基准和时间；判断与事实分开，不能把供应商资金指标当作投资者真实身份，不承诺收益或持续监控。
