# 股票复盘

交付一份从大盘到板块再到个股的复盘，让读者知道发生了什么、判断依据是什么、下一次观察什么。保留原资料的资金、情绪、强弱视角，把经验口诀转成可验证的观察条件。

## 确定范围与取数

1. 从用户上下文确认市场、交易日或区间、报告截止时点、自选或持仓及重点问题。没有指定个股时先完成大盘和板块，个股层标记缺失；不要擅自把热门股当成用户持仓。
2. 检查可用的只读行情、公告工具与用户文件。索引、证券代码、行情时间戳和单位必须明确。需要新数据时先取证；连接不可用时使用已有材料并注明范围，不能补造数据。没有足够数据分析的层级暂停结论，列出最少缺失项，继续其他层级。
3. 明确基准指数和股票池，不沿用未定义的“四大指数”。未指定时可选择与目标市场匹配的代表性指数并说明选择；股票与板块使用同区间收益率及兼容复权口径。
4. 盘后报告区分行情收盘时间与公告披露时间；收盘后公告可列为下一交易日信息，不能用来解释当日盘中决策。历史复盘只用当时可得的信息评价决策。

计算指标、处理资金身份、对比数据或推演交易时，按需读取 [references/evidence.md](references/evidence.md) 对应部分。运行不依赖仓库 inbox 或另一个 Skill。

## 按三个层级分析

三个层级均检查下表三条线索。缺失指标写明“未提供／不可核实”，不为凑齐表格推断。

| 层级 | 资金与成交：钱体现在哪些交易活动中 | 赚钱效应与情绪：上涨是否广泛、能否延续 | 相对强弱：谁占优、优势是否持续 |
| --- | --- | --- | --- |
| 大盘 | 指数及全市场成交量／额、相较前日与可比窗口的变化；有数据时列成交量和成交额前 10，分开排序 | 涨跌家数、涨跌停分布、涨跌幅分布；有数据时看昨日强势股后续表现、连板与炸板，明确样本和定义 | 各指数与大小盘风格差异、趋势位置；对照指数和个股广度，识别指数上涨但多数个股承压的情形 |
| 板块 | 领涨领跌板块成交额占比、放缩量；可得且同口径的资金流变化 | 内部上涨比例、涨停聚集、龙头与其他成份股是否共同走强，分辨少数股票拉动与板块扩散 | 板块相对大盘表现、连续多个交易日的排名和持续性、领涨股／高成交额核心股／跟随股的分化、主线候选与轮动迹象 |
| 个股 | 成交量、成交额、换手率与趋势位置的组合；资金流仅作供应商统计参考 | 回调承接、冲高回落、强势能否保留到收盘，结合所在板块赚钱效应；不凭涨跌推断持有者心理 | 对照大盘和板块的区间收益率，量价配合、关键支撑压力、突破或跌破后的表现；需要且有数据时再看分时和均价线 |

依次完成后解释三层关系：个股走强是否有板块配合，板块强势是否发生在整体普涨中，指数与赚钱效应是否背离。相互矛盾的证据保留并解释，不用单一强势指标盖过其他层级。

### 板块与个股的判断方式

- 催化因素先核对政策、公告或新闻原文及披露时间，再区分已知事实、可能影响和价格实际反应。公告类型本身不能直接决定利好或利空。
- 主线候选需要持续性、内部广度、成交参与和催化证据共同支持；缺少历史序列只能说当日强势。原文的“3 只涨停”“连续 3 天”等不能单独判定主线。
- 为个股标明相对基准及区间，列出支持强势与反对强势的证据。缓涨缩量、V 形、台阶或价量背离仅是形态，不等于控盘、洗盘、出货或必然转折。
- 支撑压力位须由用户提供或可见价格结构推导，并写明依据与观察窗口。没有行情时不编价位；不要把支撑直接变成无条件买点。

## 有记录时复盘交易

用户要求回顾操作或提供交易记录时，在行情分析后补充：事前计划 → 当时可得信息 → 委托与成交 → 费用及结果 → 执行偏差 → 下一轮可检验改进。

分别讨论市场共振、个股假设和执行问题，证据不足就保留未知。没有事前计划不能评价“是否遵守系统”；单笔盈利不证明能力，亏损不证明失控。心态仅根据用户自述或日志。放弃交易的反事实须写明当时触发条件、成交可行性、费用及卖出约束，不能使用事后最优价。

## 交付

默认简体中文，深度随问题调整，保留以下内容：

1. **范围与结论**：交易日／区间、数据截止、来源、覆盖缺口，先给一句有依据的总体判断。
2. **大盘 → 板块 → 个股**：各层列关键事实、解释、反证与待确认项；数字附单位与来源，计算结果说明比较基准。只给单股材料时，大盘板块保留缺口说明，不编造背景。
3. **交易与自身复盘**：仅在输入支持时出现，不要求用户为普通行情复盘提供账户或心态资料。
4. **下次观察清单**：对象、支持原判断的触发条件、使判断失效的条件、所需新证据。有用户计划时对照计划，无计划时只给观察条件，不替用户编仓位或风险预算。

每个重要判断能追溯到数据或来源；解释不冒充因果结论；不承诺盈利。本 Skill 交付分析，调用本身不包含下单或修改账户。
