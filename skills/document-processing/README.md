# 文档处理

收录以文档文件的结构、格式、数据或批处理结果为主要交付的 Skill。以文章观点、表达和风格为主的工作归入[写作](../writing/README.md)。

## 整理方向

以下是分类建议，不代表已实现的 Skill；有实际提示词时再创建相应目录。

| 类型 | 可整理的任务 |
| --- | --- |
| Word | 格式规范、样式排版、修订、模板填充 |
| PDF | 文本提取、OCR、拆分合并、页面检查 |
| 表格 | 数据清洗、公式处理、汇总分析、表格格式化 |
| 演示文稿 | 大纲转幻灯片、版式调整、图表制作 |
| 通用处理 | Markdown 转换、批量命名、版本对比、交付检查 |
